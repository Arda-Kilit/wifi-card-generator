# wifi-card-generator
Bu web sitesi, kullanıcıların kablosuz ağ (Wi-Fi) adını (SSID) ve şifresini girerek anında dinamik bir QR kod oluşturmasını sağlayan pratik bir araçtır. Telefon kamerasıyla taranan bu kod sayesinde misafirleriniz şifre girmeden kolayca internete bağlanabilir. Ayrıca oluşturulan bu Wi-Fi kartını tek tıkla yazdırabilirsiniz.
